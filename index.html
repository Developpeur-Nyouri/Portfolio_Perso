// 04 · VEILLE TECHNOLOGIQUE

Veille techno

La veille technologique, c’est le fait de se tenir régulièrement au courant des nouveautés et des évolutions dans le domaine de l’informatique. En tant qu’étudiant en BTS SIO, je regarde principalement ce qui se passe dans le développement web, la cybersécurité, l’intelligence artificielle et le cloud. Cela me permet de découvrir de nouvelles technologies, d’améliorer mes connaissances et de mieux comprendre les évolutions du métier.

Intelligence Artificielle
L'essor des LLMs et l'IA générative en 2025
Les modèles de langage comme GPT-4, Claude et Gemini révolutionnent le développement logiciel. GitHub Copilot et les assistants IA intégrés aux IDE changent radicalement la façon de coder, avec une productivité augmentée de 30 à 50%.
Avril 2025
LLM Copilot
Développement Web
React 19 et l'évolution des frameworks JS
React 19 introduit les Server Components stables, les Actions et une gestion améliorée des formulaires. Next.js 15 et les nouvelles approches de rendu côté serveur dominent le paysage du développement front-end moderne.
Mars 2025
React Next.js
Cybersécurité
Zero Trust : le nouveau paradigme de sécurité
L'architecture Zero Trust devient le standard dans les entreprises. L'authentification multifactorielle, la micro-segmentation réseau et l'accès au moindre privilège sont désormais incontournables face aux cyberattaques croissantes.
Février 2025
Zero Trust MFA
Cloud Computing
Kubernetes et la conteneurisation en entreprise
Kubernetes s'impose comme l'orchestrateur de référence. Les architectures microservices et serverless sur AWS, Azure et GCP permettent une scalabilité sans précédent. Le FinOps émerge pour optimiser les coûts cloud.
Janvier 2025
K8s Docker
Intelligence Artificielle
IA et cybersécurité : détection des menaces
Les algorithmes de machine learning révolutionnent la détection d'intrusions et l'analyse comportementale. Les SIEM nouvelle génération intègrent l'IA pour réduire les faux positifs et accélérer la réponse aux incidents.
Mars 2025
ML SIEM
Développement Web
WebAssembly et les nouvelles frontières du web
WebAssembly (WASM) permet d'exécuter du code C++, Rust ou Python dans le navigateur à des performances proches du natif. Des applications comme Figma et AutoCAD web exploitent cette technologie.
Avril 2025
WASM Rust
